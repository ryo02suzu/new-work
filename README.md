# URIKO（ウリコ）

> ネットショップの **“売る言葉”** を、AIがまるごと量産する。
> 商品名と特徴を入れるだけで、**商品説明文（複数トーン）／キャッチコピー／SEOタイトル・キーワード／SNS投稿／検索広告コピー** を一発生成。

ECショップ運営者の「毎週、出品・販促の文章を書く時間」をゼロにするための、出品コピー自動生成ツールです。

---

## なぜこれなのか（戦略メモ）

市場・収益のリサーチから出した結論：

- **消費者向けアプリ＝最初のお金から最も遠い**。アプリの99.5%は失敗、発見性は壊れ、無料→課金転換は2〜5%（課金1人あたりインストール単価の20〜50倍）。だから **Webで・お金を持つ人に・直接** 売る。
- 最初の売上が立つのは **「汎用ツール」ではなく「縦に特化したAI」**。AIコンテンツ系は月$19〜99、業種特化は競合が薄く高リテンション。
- **ネットショップ運営者**は「毎週の販促文」という繰り返しの痛みがあり、集客にお金を払う層。ChatGPTは汎用すぎるので、**EC出品に最適化された型**で勝てる。

設計思想：**「AIに会話させる」のではなく「AIに“売れる成果物”を作らせる」**。

---

## いま動くもの（MVP）

- **出品パック生成** — Claude（`claude-opus-4-8`）が、1商品から以下を一括生成：
  - キャッチコピー（5案）
  - 商品説明文（標準 / 感情訴求 / スペック重視 の3トーン）
  - 訴求ポイント（箇条書き）
  - SEOタイトル & 検索キーワード
  - SNS投稿（X / Instagram、ハッシュタグ付き）
  - 検索広告コピー（見出し＋説明 ×2）
- **CSV一括生成** — 複数商品をまとめて出品パック化（`/api/bulk`）。v1最優先の課金機能。
- **モール別テンプレ出力** — 楽天 / Amazon / BASE / メルカリShops 向けに「そのまま貼れる」形へ整形。
- **ワンクリックでコピー** — 各成果物（や出品パック丸ごと）をそのまま商品ページ・広告に貼れる。
- **キー無しでも動く** — `ANTHROPIC_API_KEY` 未設定時はテンプレート生成にフォールバック。
- **先行登録（プリセール）** — `#presell` セクションでメール先行登録（リリース時に先行価格で案内）。

`サンプルを入れる → 出品パックを生成する` で、信楽焼マグカップのフルパックが出ます。

## セットアップ

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定（任意）
npm run dev                  # http://localhost:3000
```

本番ビルド: `npm run build && npm run start`

### 環境変数

| 変数 | 必須 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 任意 | AI生成に使用。未設定ならテンプレート生成にフォールバック。 |
| `URIKO_MODEL` | 任意 | 生成モデル。既定 `claude-opus-4-8`。コスト重視なら `claude-haiku-4-5` 等。 |

## 技術構成

- **Next.js 16（App Router）+ React 19 + TypeScript**
- **Anthropic SDK** — 構造化出力（JSON Schema）で出品パックを安定生成
- `app/api/generate` … 商品情報 → 出品パック生成
- `app/api/waitlist` … 先行登録（MVPは受領のみ。本番は Supabase / ConvertKit 等に保存）
- Vercel にそのままデプロイ可能

```
app/
  page.tsx              # LP + 生成ツール + 先行登録（クライアント）
  api/generate/route.ts # 出品パック生成
  api/waitlist/route.ts # 先行登録
lib/
  generate.ts           # Claude生成 + テンプレートのフォールバック
  types.ts              # 共有型・トーン
  sample.ts             # デモ用サンプル商品
```
