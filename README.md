# ZEIPILOT（ゼイパイロット）

> フリーランス・個人事業主のための **AI経理エージェント**。
> 取引データを貼り付けるだけで、AIが「事業の経費か / プライベートか」を判定して自動仕訳し、
> いまの **手取り** と払う **税金の概算** を即座に計算します。

確定申告は年1回の地獄。freee や弥生は「入力を楽にする」ところまでで、結局は自分で仕訳・判断する必要があります。
ZEIPILOT は **AIに丸投げできる経理アシスタント** を目指します。最初のクサビは「数字のヤバさが一目でわかる体験」。

---

## なぜ勝てるのか（ポジショニング）

市場調査の結論：個人向け家計簿も法人会計も寡占の **レッドオーシャン**。ただし**成長**している市場で、
真ん中を避けて **特定セグメント × 文脈特化** に刺せば空きがある。ZEIPILOT は次の3条件を満たす場所を取りにいく：

1. **激痛** — 確定申告は締切があり先延ばしできない。
2. **支払い意欲** — フリーランスは「時間を金で買う」層。
3. **ChatGPTが入れない堀** — 日本の税制 × 実データ × 実行（＋責任）。汎用AIチャットには出せない価値。

設計思想は一貫して **「AIに会話させる」のではなく「AIに仕事をさせる」**。

---

## いま動くもの（MVP）

このリポジトリは動作するMVPです。

- **AI自動仕訳** — Claude（`claude-opus-4-8`）が各取引を `売上 / 経費 / プライベート` に分類し、勘定科目・控除可否・確信度・理由まで返す。
- **手取り＆税金の概算** — 売上・経費から、所得税・復興特別所得税・住民税・個人事業税・青色申告特別控除を加味して、税引後の手取りを計算。
- **要確認ハイライト** — 確信度の低い取引を可視化（AIが迷ったものだけ人間が見ればよい）。
- **キーが無くても動く** — `ANTHROPIC_API_KEY` 未設定でもルールベースのモック分類でデモ可能。

`サンプルデータを入れる → AIで分析する` を押すと、年間の売上・経費・税金・手取りと、自動仕訳テーブルが出ます。

## セットアップ

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定（任意）
npm run dev                  # http://localhost:3000
```

本番ビルド:

```bash
npm run build && npm run start
```

### 環境変数

| 変数 | 必須 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 任意 | AI仕訳に使用。未設定ならモック分類にフォールバック。 |
| `ZEIPILOT_MODEL` | 任意 | 分類モデル。既定 `claude-opus-4-8`。コスト重視なら `claude-haiku-4-5` 等。 |

## 技術構成

- **Next.js 16（App Router）+ React 19 + TypeScript**
- **Anthropic SDK** — `messages` の構造化出力（JSON Schema）で仕訳結果を安定取得
- APIルート `app/api/analyze` が「分類 → 集計 → 税計算」を担当
- Vercel にそのままデプロイ可能

```
app/
  page.tsx             # 入力UI + 結果ダッシュボード（クライアント）
  api/analyze/route.ts # 分類→集計→税計算
lib/
  categorize.ts        # Claude仕訳 + ルールベースのフォールバック
  tax.ts               # 個人事業主の税金概算エンジン
  csv.ts               # 取引CSVパーサ
  types.ts             # 共有型・勘定科目
  sample.ts            # デモ用サンプル取引
```

## ロードマップ（ゼロ→売上）

| フェーズ | 内容 | 課金 |
|---|---|---|
| **0. MVP（now）** | CSV貼付 → AI仕訳 → 手取り・税金の概算 | 無料（フック） |
| **1. 連携** | 銀行・カードのAPI連携（電子決済等代行業）で自動取込。家事按分の自動提案 | フリーミアム |
| **2. 申告下準備** | 青色申告決算書・確定申告書のドラフト生成、e-Tax用データ書き出し | 月1,000〜2,000円 |
| **3. エージェント化** | 予定納税ぶんの現金を自動で別口座に確保、節税提案、インボイス対応 | 上位プラン |

**最初の堀**：連携の安定性とカテゴリ分類精度（継続/解約の分水嶺）。ここを本気で詰める。

> ⚠️ 本アプリの税額・手取りは **概算・目安** です。最終的な申告は税理士・税務署にご確認ください。
